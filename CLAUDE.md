## Lessons / gotchas
- 6 GB VRAM: at 8 slots, phi4-mini (28/33 layers) and ministral-3 (21/27) spill to CPU and slow down.
  Use 4 slots for them and 8 for llama, qwen and gemma.
- Killing `ollama.exe` does **not** kill its `llama-server.exe` runner. An orphan held about 6 GB of RAM.
  Kill by PID with `/T`, and clean up runners whose command line contains `ollama_models`.
  **Never kill `ollama.exe` by image name**, because the user's own Ollama (port 11434, tray app) must
  stay untouched.
- llama-server's default host prompt cache (`--cache-ram`, up to 8 GiB) plus the orphan exhausted RAM
  (0.3 GB free). Claude Code then **reaped the background driver**. Fixed with
  `LLAMA_ARG_CACHE_RAM=0`. After the fix the runner uses about 0.9 GB.
- The SQLite cache commits every 200 calls, so progress is not visible in the cache until a commit.
  Everything is resumable: re-running the driver repeats nothing that was already cached.
- Rendering the docx: Word COM works (`render.ps1` in the scratchpad: docx to PDF), and pymupdf (in the
  venv) turns PDF pages into PNG. No LibreOffice, pandoc or docx-js is installed.
- Measured throughput is about 1.1–1.5 judge calls/s (8 slots) and about 0.7 (Ministral, 4 slots).

## New scripts and conditions (2026-10-15)
- `scripts/fill_paper.py`: template -> .tex. Slot forms `@@Macro@@`, `@@CORR|CORRCI|CORRP:cfg:metric@@`,
  `@@PJ|PJCI|PJP:judge:metric@@`, `@@DOM|DOMCI:...@@`, `@@SEL|SELCI:...@@`, `@@VG|VGCI|SOLO:judge@@`,
  `@@IMP|IMPCI:...@@`, `@@EQ|WORDS|FB|NSPLIT:...@@`, `@@TABLE:name@@`, and the wrappers
  `@@ABS:...@@` (magnitude, for "costs X pp"), `@@NEG:...@@` (typographic `$-$`) and
  `@@WORD:...@@` (small integer as a word). **Exits 1 and writes nothing on any unresolved slot.**
- `scripts/check_paper_numbers.py`: fails on literals in the template that no config value, design
  constant or computed macro explains. `scripts/check_tex.py`: LaTeX-free structural check (leftover
  slots, per-row cell counts vs a brace-matched column spec, ref/label and cite/bibitem symmetry,
  brace/environment balance, figure files).
- Controls, in `biojudge/perturb.py` + `pipeline.py` + `analysis.py`:
  **placebo** (two neutral length-matched sentences, no cue) is the floor every ASR is read against;
  **consensus** (held out of the normalizer's instructions) tests generalization;
  **symmetric** applies each edit to R+ to separate persuasion from perturbation;
  **strip-only** (`base_strip`) deletes markup and bracketed text with a regex and nothing else,
  which separates the normalizer's cue removal from its rewrite.
- Estimators added: repair rate RR, net rate, placebo-adjusted rate, per-edit `dacc`/`symdacc`,
  tie-rule sensitivity, verification gain, TOST + MDE, Holm over the 4 primary contrasts.
- **Minus signs**: `ci_str` and the `Reg*CI` macros emit `$-$`, not a hyphen. CIs appear in prose as
  `8.2~pp [4.7, 11.8]` (no wrapping parens) except where the value is an appositive, where the pair
  is wrapped once: `(5.1~pp [$-$6.5, 17.1])`.

## Headline results (real; main run 2026-09-26, controls 2026-10-15)
- Judges are near chance: Acc 54.7% [51.5, 58.0], mean kappa 0.09, Flip 39.2%. Llama is *below* chance
  (47.6%; 35.8% on literature). The manipulations steer an already near-arbitrary decision.
- Verification gain is negative for all four judges: -23.6 to -2.5 pp, -9.7 pooled. Two-option items
  -21.8; four-option -3.4 (CI spans 0). Framing: a verifier is not worth adding here, not "verifiers
  are useless".
- **RQ1 interaction is NULL**: IC = 0.9 pp (p = 0.702, Holm 0.702), TOST against +-5 pp holds (p=0.041),
  MDE 6.7 pp. But beta(WA x PW) = -5.6 pp (p = 0.004): position x length *is* super-additive.
  Main effects: WA -19.8, PW -7.6, PR +12.4, SW -8.7 pp (all p < 0.001).
- Self-preference is model-specific: ministral +59.2 pp, qwen -12.7, gemma -7.9, llama +5.1.
- **Controls reframe the attacks.** Placebo floor 14.6% [11.6, 17.9]; repair rate 47.1%. Only 3 of 5
  edits clear the floor (citation +8.2, format +4.9, injection +26.0); authority and confidence do not.
  By accuracy only 2 cost anything: injection -16.1 pp, citation -4.4. Format shifts verdicts above the
  floor but repairs as many as it breaks, so it costs 0 -- report dAcc beside the adjusted rate.
  Confidence *helps* (+3.3 pp). Symmetric edits give three mechanisms: injection and citation persuade
  (symdacc +17.7 / +6.0), confidence repels (-4.1 on R+ too), authority and format are inert.
  Held-out consensus cue: -2.4 pp at base, indistinguishable from the floor after normalization.
- **Strip-only ablation is the key defense result.** A regex that deletes markup and bracketed text
  beats the LLM normalizer on attacks (injection 40.7 -> 8.9% vs 18.2%; ASR_any 43.9 vs 44.5) and buys
  **zero** accuracy (-0.4 [-2.3, 1.3]), zero VB and zero SPB change. So cue removal stops the edits
  (no LLM needed) and the rewrite's +3.2 pp is **length equalization**, not knowledge: the gain is the
  same on items phi knows (+3.3) and does not (+2.9), and LLM-rewrite accuracy (57.9%) equals
  deterministic-fallback accuracy (58.0%). Phi scores 64.4% solo, so it had knowledge to leak.
- Debias clause: dAcc 0.0, ASR_any +3.4 (CI includes 0). Full pipeline dAcc +3.8 but Holm p = 0.452,
  so **do not claim** the full pipeline improves accuracy. Juries *worsen* Flip (+6.7, +7.4) while
  cutting ASR.
- Domain stability: W_acc 0.82, raw p 0.032 but **Holm p 0.097** -> no ranking is stable. The draft's

- Best-of-4: clean 28.8%, attacked **19.9%**, below the 23.1% effective chance (unparseable = miss).

- **Greedy is not reproducible on this stack**: 2,336 re-decodes of identical prompts give 11.9%

  is reported as a limitation. Parse failures are the same phenomenon: 68.3% reparse on a second decode.
